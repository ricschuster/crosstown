# Security

Crosstown is a static, client-side browser game: there is no backend, no
accounts and no user data leaves the browser (saves live in `localStorage`).
The realistic surface is the build and its dependencies.

If you find a vulnerability, please report it privately through GitHub's
[security advisories](https://github.com/ricschuster/crosstown/security/advisories/new)
rather than a public issue. This is a solo project, so expect a reply in days,
not hours.

Anything that is not a vulnerability (a bug, a crash, a driving problem) is
welcome as an ordinary issue.
